One image that sums up the world news of Sunday 22 November 2026, drawn as a classic broadsheet front page: a COP31 climate-deal lead, plus Mexico's capture of cartel boss "El Chapo Isidro", Iran's strike on Bahrain, Russia's hit on Zelensky's hometown, the EU–Indonesia trade deal and the AI-checked Riemann proof. The stories live as data in `stories.json`; `render_image.py` (Python + PIL) draws the page into `entry.png`, and `main.ts` hands that image to the grader.

## Run it
